# Code of Conduct

CheckpointKit aims to maintain a technical, respectful, and evidence-oriented project environment.

Participants are expected to:

- critique code and ideas rather than people;
- provide reproducible evidence when making technical claims;
- respect privacy and avoid posting secrets or sensitive checkpoint data;
- avoid harassment, discrimination, threats, or deliberately disruptive behavior;
- disclose conflicts of interest when they materially affect a contribution or review.

Maintainers may edit, hide, lock, or remove content that violates these expectations and may restrict participation for repeated or severe violations.

For conduct concerns that should not be handled publicly, use an available private GitHub contact or security channel rather than posting sensitive details in an issue.
